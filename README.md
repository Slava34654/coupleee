# CoupleJoy — аналог (Python + Android Studio)

Приложение для пары: настроение, счётчик любви и серия дней, ежедневный
вопрос с ответами обоих, викторины с % совместимости, идеи свиданий,
общий журнал, обратный отсчёт до событий.

## Состав
- `backend/` — Python FastAPI + SQLite (REST API, порт 8000)
- `android/` — нативное Android-приложение (Kotlin + Jetpack Compose +
  Retrofit), открывается в Android Studio

## 1. Бэкенд (Python)
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```
Проверка: http://127.0.0.1:8000/docs (Swagger), тесты: `python test_api.py`

## 2. Приложение (Android Studio)
1. Дотяните установку Android Studio и поставьте через SDK Manager:
   Android SDK Platform 34 + эмулятор.
2. В Android Studio: File → Open → папка `android/` → дождаться Gradle Sync
   (Gradle и зависимости скачаются сами).
3. Запустите бэкенд (п.1), затем Run ▶ на эмуляторе.
   Эмулятор видит бэкенд по адресу `http://10.0.2.2:8000`
   (уже прописан в `api/Api.kt` → `BASE_URL`).
   Для реального телефона в том же Wi-Fi укажите IP компьютера,
   например `http://192.168.1.5:8000/`.
4. В приложении: введите имя → «Создать пару» → покажите код партнёру.
   Партнёр: имя + код → «Присоединиться». user_id сохраняется на устройстве.

## Экраны
Главная (дни вместе, серия, настроение обоих) • Вопрос дня (+викторины) •
Идеи свиданий (+«Мне повезёт») • Журнал • Обратный отсчёт.
