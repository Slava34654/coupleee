# Legacy Android Client

Архив старого Kotlin/Jetpack Compose клиента. Основным клиентом является Flutter-приложение из отдельного checkout.

Открывайте эту папку как отдельный Android Studio проект. Generated-файлы и `local.properties` не хранятся в Git.

Задача `exportDebugApk` сохраняет APK в `android/Enrwine.apk`, откуда backend выдаёт его через `/Enrwine.apk`.
